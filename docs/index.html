    03 / UNDER THE HOOD

    The boxes are clues.
    Here’s what they tell us.

    The extractor finds card-shaped regions. Recognition then compares the rectified image with reference cards. Reading text is a separate, inspectable source of evidence. Mana symbols, the type line, artist credits, and rarity are not independent match channels in this demo.

    Read the source ↗
    01

    Title bar

    OCR reads the card name. Normalised fuzzy matching tolerates small recognition errors. Titles often identify the game object, while reprints can keep the same name.

    02

    Artwork & full card

    Luminance structure, artwork colour, and a perceptual hash provide visual similarity. Difficult perspectives can use local features and geometric verification. Artwork shared by reprints leaves the exact printing ambiguous.

    03

    Rules text

    Yes: fuzzy matching can use OCR from the rules box. Rare words carry more information than a common phrase. Printed wording can differ from current Oracle text; reminder text, language, and a short text box can limit the evidence.

    04

    Bottom bar

    A recognised set code and collector number are strong printing clues. Modern frames give these fields a consistent home; older layouts need different boxes. Some early cards have no printed collector number.

    A NOTE ON CERTAINTY

    It’s allowed to say
    “I’m not sure.”

    The demo searches a small, disclosed catalog. An absent card can resemble a present one. A strong score, a clear margin over other identities, and agreement between clues are more informative than a single top result.

    Visual ranking and text ranking remain separate here. Neither has been calibrated as a probability, and text evidence does not silently change the visual match.
