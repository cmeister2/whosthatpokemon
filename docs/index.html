    Notes

    This demo searches 28 public printings. magicextract detects card-shaped regions; recognition compares those crops with the catalog. A card missing from the catalog can still resemble a reference.

    Identity means the card itself; printing means a particular release. Printings can share a title and artwork. Matched clears the similarity and margin thresholds, ambiguous means competing candidates are too close, and unknown means the best candidate falls below the threshold.

    Matching notes
    Artwork and full card
    Luminance structure, artwork colour, and a perceptual hash contribute to visual similarity. Local features and geometric verification provide a fallback for difficult perspectives. Shared artwork can leave the printing ambiguous.
    Title
    OCR and normalised fuzzy matching tolerate small reading errors. A name usually identifies the card, but does not distinguish its reprints.
    Rules text
    Fuzzy matching gives distinctive words more weight than common phrases. Printed wording can differ from current Oracle text. Reminder text, language, and short rules boxes can limit the result.
    Bottom bar
    A readable set code and collector number together can identify a printing. Modern frames place these fields consistently; older layouts need different regions. Some early cards have no printed collector number.

    Visual and text rankings are separate. Text search does not change the visual match, and neither ranking is calibrated as a probability.

    OCR uses approximate regions and an English model. Unusual frames need custom regions. Mana symbols, the type line, artist credits, and rarity are not independent matching inputs in this demo.
